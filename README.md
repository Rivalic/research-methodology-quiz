# Research Methodology & Aptitude Quiz (120 Questions)

An interactive, responsive single-page quiz application covering 120 questions across 12 research methodology assignments.

## Features
- **Instant Answer Feedback**: Choose an option to see immediate validation. Wrong answers are highlighted in red, and the correct answer(s) are illuminated in green with clear explanations.
- **Support for Multi-Select**: Handles multiple correct choices with selective grading.
- **120 Question Palette**: Quick jump grid showing answered, correct, and wrong status for each question.
- **Search & Filters**: Filter by assignment (1-12), status (unanswered, correct, mistakes, bookmarks), or search by keywords.
- **Dark/Light Mode**: Full theme customization.
- **Audio Feedback**: Subtle Web Audio sound effects on correct and incorrect selections.
- **Persistent Progress**: Automatically saves your score and answers locally.

## Deploy on Vercel
Ready to deploy with zero configuration on [Vercel](https://vercel.com).
